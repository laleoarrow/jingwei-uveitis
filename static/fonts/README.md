# Local report fonts

The four locally downloaded WOFF2 files use the Helvetica Neue LT Std font programs (version 1.029), not macOS Helvetica Neue or Arial substitutes. CSS loads them from this local server; report viewing does not contact a font CDN. Each face contains 253 glyphs / 252 mapped characters, rather than a subset extracted from the Mayo PDF.

Downloaded at the user’s request on 2026-10-10 from the public pages below. The source is a third-party font archive, not the foundry. Commercial/self-hosting and redistribution rights have not been established. Font binaries are excluded from Git; obtain suitable licensed files before distributing the application.
